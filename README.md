# playwright-training-0325
Training repository for automation with Playwright Java Script

Scenario1: How to handle multi line csv files? WE want to upload the test data through csv with multiple lines, we saw a working example of single line csv, please demonstrate a multi-line example as well
Scenario2: How to fetch API responses along with UI validation. When navigating a particular page, there are API calls in the background. We want to fetch the response of one endpoint and use the param from response to validate the display on the next screen in UI. E.g. Page 1 calls API1 in background. From response body of API1, capture param 2. Navigate to Page 2 and assert the value of Param 2 against a field displayed in UI
Scenario 3: Capturing the look and feel. On each page in a journey, there is a Header and message displayed on the page. We want to capture and validate the look and feel of the header and message on each page. This should include the placement of text, Font of text and color if possible.
Scenario 4: Email validation. We want to validate the auto emails generated preferably through mailinator or any other third party. This should include From, To and content on the email.
